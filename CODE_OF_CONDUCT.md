# Code of Conduct

This project follows the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## TL;DR

- Be welcoming and patient.
- Disagree about ideas, not people.
- No harassment, slurs, doxxing, or sustained disruption.

## Reporting

If you experience or witness behavior that violates the Covenant,
contact the project owner at **alex@alexreich.com** with
`[sitepix-conduct]` in the subject. Reports are confidential.
Enforcement decisions follow the
[Contributor Covenant Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
